# Luna Desktop

Персональный ассистент для компьютера. Значок Луны всегда поверх окон. Пользователь обращается к ней голосом, текстом или горячей клавишей. Луна видит контекст по запросу, действует на компьютере с подтверждением, помнит задачи и предпочтения.

Статус: **фазы 0–4 пройдены** (каркас, модель, действия с подтверждением, память). Следующая — фаза 5, голос.

Запуск: `cd apps/desktop && npm install && npm run dev`.

Модель по умолчанию — OpenAI (`gpt-4.1-mini`). Ключ сохраняется в Keychain один раз:

```
security add-generic-password -s luna-desktop -a openai -w ВАШ_КЛЮЧ -U
```

Локальная модель через Ollama включается переменной `LUNA_PROVIDER=ollama`.

## Принципы

- Работает по запросу, без непрерывного наблюдения за экраном.
- Любое действие, которое меняет что-то, требует подтверждения (кроме режима полного доступа, который включает пользователь).
- Деньги, платежи и отправка сообщений от имени пользователя — всегда с подтверждением.
- Модели: локальные (Ollama) или облачные по ключу пользователя. Ключи никогда не попадают в репозиторий.

## Платформы

Первая — macOS. Затем Windows и Ubuntu.
