# Полное окно Луны и два режима работы — дизайн

Дата: 26 ноября 2026. Статус: на согласовании у автора.
Основа: обсуждение в чате (части 1–4 одобрены автором), макет фонов: https://claude.ai/artifact/RxXavtDXV4u9vL6gRdSZxe (вариант «Созвездия»).

## 1. Цель

Луна должна быть не только полезной, но и красивой: «чтобы все поражались». Сейчас полное окно — заготовка: одна лента, тесные блоки, кнопка «Отправить» обрезается, настройки свалены в одну колонку, значок остаётся на экране вместе с окном.

**Критерии успеха:**
- На экране всегда один режим: значок (с маленькой панелью) или полное окно. Переход в обе стороны — горячей клавишей и кнопкой, с плавной анимацией.
- Полное окно — панель управления: беседы, задачи, память, журнал, настройки. Размер не ограничен.
- Беседы сохраняются между запусками.
- Настройки разбиты на понятные категории.
- Формы ровные: ничего не обрезается, кнопки нормального размера.
- Фон «Созвездия» в обеих темах; фон есть только у сообщений и поля ввода, у чата общей подложки нет.
- Тёмная и светлая темы, контраст текста не ниже 4.5:1.

## 2. Решения автора и допущения

**Решения автора:**
- Беседы хранятся все и всегда (вариант A).
- Переключение режимов — ⌥⇧Space (вариант A).
- Архитектура окон — два окна и согласованная анимация (вариант A).
- Фон — «Созвездия», в тёмной и светлой теме.
- У чата нет общей подложки: фон только у сообщений и поля ввода.

**Допущения (автор не возражал):**
- Маленькая панель и полное окно работают с одной активной беседой.
- Подтверждения действий видны и в полном окне, прямо в ленте.
- Красная кнопка закрытия полного окна возвращает значок, а не завершает приложение.

## 3. Режимы и окна

**Состояние.** Главный процесс хранит одно поле `mode: 'orb' | 'window'`. Только оно решает, какое окно показано.

| Режим | Что на экране |
|---|---|
| `orb` | окно значка; маленькая панель по требованию |
| `window` | полное окно; значок и панель скрыты |

**Переходы:**
- ⌥⇧Space — переключить режим.
- Кнопка «Открыть окно ↗» в маленькой панели (в шапке и в меню).
- Кнопка «Свернуть в значок» внизу боковой панели полного окна.
- Красная кнопка закрытия полного окна → режим `orb`.
- ⌥Space: в режиме `orb` открывает ввод в панели; в режиме `window` ставит фокус в поле ввода полного окна.
- Выход из приложения — только пункт «Выйти» (меню значка и полного окна) или ⌘Q в полном окне.

**Анимация (~250 мс, ease-out; при «уменьшить движение» — мгновенно):**
- `orb → window`: значок сжимается до 0.6 и гаснет; полное окно появляется с затуханием и масштабом 0.96 → 1, точка роста — сторона экрана, где был значок.
- `window → orb`: полное окно гаснет и уменьшается; значок появляется на прежнем месте с масштабом 0.6 → 1.
- Анимация делается в каждом окне средствами CSS. Главный процесс сначала посылает окну команду «уйти», ждёт её завершения (событие или таймаут 300 мс), потом прячет окно и показывает другое.

**Что сохраняется в настройках:** позиция значка, размер и положение полного окна, последний режим (при запуске открывается последний режим).

**Полное окно:** обычное окно macOS, минимум 720×520, полноэкранный режим, `titleBarStyle: hiddenInset`.

## 4. Беседы и данные

**Хранение** — та же база `memory.sqlite`:

```sql
CREATE TABLE IF NOT EXISTS conversations (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  summary TEXT NOT NULL DEFAULT '',
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS messages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  conversation_id TEXT NOT NULL REFERENCES conversations(id) ON DELETE CASCADE,
  role TEXT NOT NULL CHECK (role IN ('user', 'assistant')),
  text TEXT NOT NULL,
  created_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS messages_by_conversation ON messages(conversation_id, id);
```

**Правила:**
- Одна активная беседа на всё приложение; её id хранится в настройках.
- Беседа создаётся кнопкой «Новая беседа» или автоматически при первом сообщении, если активной нет.
- Название — первые 48 символов первого запроса (обрезка по слову), можно переименовать.
- Удаление — с подтверждением внутри интерфейса; удаляются и сообщения.
- В `messages` пишется только текст вопроса пользователя (без блока `<screen_content>` и без снимков) и итоговый текст ответа. Содержимое экрана в базу не попадает.
- История для модели берётся из сообщений активной беседы (последние 12 дословно) плюс её `summary`. Сжатие длинного диалога обновляет `summary` этой беседы.
- Задачи и память остаются общими для всех бесед.

## 5. Полное окно

**Боковая панель** (ширина 260, сворачивается кнопкой; при ширине окна меньше 900 — свёрнута):
- Сверху: «Луна», кнопка «Новая беседа», поиск по беседам (по названию).
- Разделы: «Чат», «Задачи» (счётчик активных), «Память», «Журнал».
- Беседы: группы «Сегодня», «Вчера», «Ранее». Двойной клик — переименовать, наведение — кнопка удаления.
- Снизу: строка статуса (режим «наблюдать/помогать» или «полный доступ» розовым), кнопки «Настройки» и «Свернуть в значок».

**Чат:**
- Лента по центру, максимум 760 px. Пользователь справа, Луна слева; ответ оформляется (абзацы, списки, код).
- У каждого сообщения своя подложка из матового стекла; общей подложки у ленты нет.
- Под ответом — строка «Прочитано: …», если читался экран.
- Индикатор «думает» — три точки в пузыре Луны, пока идёт ответ.
- Подтверждения действий — карточка в ленте: описание, «Отклонить» (фокус по умолчанию), «Разрешить». Та же карточка в маленькой панели; решение в одном месте снимает её в обоих.
- Поле ввода: многострочное (до 8 строк), Enter — отправить, Shift+Enter — перенос. Кнопка «Отправить» — круглая, 40×40, иконка стрелки, подсказка «Отправить (Enter)». Во время ответа на её месте «Стоп». Над полем — бейдж уровня доступа и название модели.
- Пустая беседа: приветствие и 4 примера запросов кнопками.

**Задачи:** две колонки — «Активные» (active, waiting, postponed) и «Готовые» (done). У задачи: название, статус (выпадающий список), срок, итог. Удаление с подтверждением.

**Память:** три отдельные карточки — «Профиль», «Паттерны», «Факты». У записи — текст, источник («вы попросили» или «предложено»), дата, удаление. Пустое состояние у каждой карточки своё.

**Журнал:** последние 200 записей, только чтение; фильтр по виду (чтение, действия, подтверждения, отказы, остановки); время, вид, описание.

## 6. Настройки

Открываются в полном окне на месте рабочей области: список категорий слева, содержимое справа. У категории — заголовок и одно предложение пояснения.

| Категория | Что внутри |
|---|---|
| Модель и сервер | провайдер из каталога, адрес, модель, ключ (Keychain), «Проверить подключение» |
| Поиск | Википедия, свой SearXNG (адрес), поиск OpenAI |
| Доступ | режим, уровень доступа, список разрешённых, исключённые приложения, полный доступ с согласием |
| Голос | пол Луны; пометка «выбор голоса появится в следующей версии» |
| Память и Obsidian | папка зеркала |
| Внешний вид | тема (системная, тёмная, светлая), фон (вкл/выкл), плотность звёзд (мало, средне, много) |
| Горячие клавиши | ⌥Space, ⌥⇧Space (просмотр) |

В маленькой панели пункт «Настройки» открывает полное окно сразу на настройках.

## 7. Визуал

**Токены.** Все цвета, радиусы, тени и отступы — CSS-переменные в одном файле `tokens.css`. Две палитры: `[data-theme="dark"]` и `[data-theme="light"]`; системная тема выбирает одну из них. Компоненты не содержат литералов цвета.

**Тёмная тема:** фон — глубокий сине-чёрный, акцент — лунный голубой, ИИ — фиолетовый.
**Светлая тема:** фон — светлое «рассветное» небо (бледно-сиреневый → почти белый), тот же акцент, затемнённый для контраста.
Контраст текста не ниже 4.5:1 в обеих.

**Фон «Созвездия»** (компонент `ConstellationBackground`, canvas):
- 40 / 64 / 90 звёзд для плотности «мало / средне / много» (по умолчанию «средне»); медленный дрейф; линии между звёздами ближе 24% меньшей стороны, прозрачность по расстоянию.
- Рядом с курсором (радиус ×1.4) появляются связи с курсором.
- Ночью — светлые точки и серебристые линии; днём — искры цвета акцента и сине-фиолетовые линии.
- Только за лентой чата; число звёзд ограничено плотностью, плотность линий считается за O(n²) не более чем для 90 точек; на паузе, когда окно скрыто или свёрнуто; при «уменьшить движение» — один неподвижный кадр.

**Формы.** Поля и кнопки — высота 40, радиус 12, подпись над полем, видимый фокус (кольцо 2 px акцентом), disabled — прозрачность 0.45 без смены размера. Тексты переносятся, а не обрезаются.

**Шрифты.** Inter для текста, системный шрифт как запас. Шкала: 12 / 13 / 14 / 16 / 20 / 28.
**Отступы:** кратны 4 и 8.
**Иконки:** простые встроенные SVG.

**Единый язык.** Значок и маленькая панель переходят на те же токены и следуют теме.

## 8. Архитектура кода

Цель — разделить разросшиеся файлы по ответственности, не меняя поведение агента.

**Главный процесс (`src/main`):**
- `windows/orb.ts`, `windows/panel.ts`, `windows/main-window.ts` — создание и размещение окон.
- `modes.ts` — переключатель режимов (`orb`/`window`), анимация, сохранение режима.
- `conversations/store.ts` — таблицы бесед и сообщений; `conversations/service.ts` — активная беседа, история для модели, названия.
- `ipc/` — регистрация каналов по областям (чат, беседы, задачи, память, журнал, настройки, режимы).
- `index.ts` — только запуск: создать хранилища, окна, зарегистрировать IPC и горячие клавиши.

**Интерфейс (`src/renderer/src`):**
- `styles/tokens.css`, `styles/base.css`, `styles/<область>.css`.
- `views/orb/`, `views/panel/`, `views/main/` (чат, задачи, память, журнал, настройки).
- `components/` — общие: кнопка, поле, выпадающий список, карточка подтверждения, ответ (`Reply`), фон (`ConstellationBackground`), иконки.
- `state/` — хуки подписки на состояние главного процесса (`useSnapshot`, `useTranscript`, `useSettings`).

**IPC (новые каналы):** `mode:get`, `mode:toggle`, `mode:changed`, `mode:leave-done`; `conv:list`, `conv:create`, `conv:select`, `conv:rename`, `conv:delete`, `conv:messages`, `conv:changed`; `tasks:update-status`, `tasks:delete`; `journal:list`. Старый `transcript` заменяется сообщениями активной беседы.

## 9. Ошибки

- База недоступна → понятное сообщение в окне и работа без сохранения бесед до перезапуска.
- Горячая клавиша не зарегистрировалась → предупреждение в «Горячих клавишах» с предложением другой.
- Анимация «ухода» не ответила за 300 мс → переключение всё равно происходит.
- Ошибки модели показываются в ленте сообщением Луны, как сейчас.

## 10. Проверка

**Автоматически (Node, без Electron):**
- `conversations/store`: создание, список, переименование, удаление с сообщениями, история последних 12 + summary, обрезка названия.
- Переключатель режимов: последовательность `orb → window → orb`, закрытие окна → `orb`, таймаут анимации.
- `npm run typecheck` и сборка `electron-vite build` без ошибок.

**Вручную (чек-лист в приложении):** переключение клавишей и кнопками в обе стороны; значок скрыт в режиме окна; беседы переживают перезапуск; подтверждение снимается в обоих окнах; формы не обрезаются при ширине 720; обе темы; фон на паузе при скрытом окне; «уменьшить движение».

Перед показом автору — `critique` и `polish`.

## 11. Вне рамок

- Голос и выбор голосов (фаза 5).
- Смена горячих клавиш из интерфейса (только просмотр).
- Поиск по содержимому бесед (только по названию).
- Синхронизация между устройствами.
